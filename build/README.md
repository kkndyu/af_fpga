# build/ - generated artefacts

Nothing in here is a source file. Everything except the bitstream can be
regenerated by running the scripts in `../scripts/`.

```
build/
  moe/out/          build output of scripts/build_moe.tcl
    moe_proto.bit     THE bitstream - the only file here worth keeping
    timing_*.rpt      timing at synthesis / placement / routing
    util_*.rpt        utilisation at synthesis / implementation
    drc.rpt           design rule check
    clock_util.rpt    clock resource usage
  logs/             simulator and build logs
```

## What was removed, and how to get it back

The tree used to carry ~230 MB of intermediates. These were deleted because they
are regenerable and were making it hard to see what actually matters:

| Removed | Regenerate with |
|---|---|
| `*.dcp` checkpoints (~124 MB) | `scripts/run_build.ps1` |
| `netsim/moe_netlist.v` (~21 MB) | `vivado -mode batch -source scripts/netlist_sim.tcl` |
| `probe/`, `synth_out/`, `physopt/` | the corresponding scripts |
| `proj/`, `probe_proj/`, `synth_proj/` | recreated on each run |
| xsim snapshots and waveform databases | re-run `scripts/sim.cmd <mode>` |
| the LED blink demo (`ledtest/`, 9.3 MB) | one-off bring-up test, no longer relevant |
| extracted PDF text and UART demo (~12 MB) | `scripts/extract_pdf_text.js` if ever needed again |

The UART pin numbers found during that extraction are preserved in
`../docs/board_pinout.md`, which is the point of keeping the conclusion rather
than the extraction.

## Scripts that need a build first

These read a checkpoint produced by `run_build.ps1` and fail with a clear message
if it is absent, rather than silently doing nothing:

- `scripts/physopt_only.tcl`  - wants `moe/out/post_route.dcp`
- `scripts/netlist_sim.tcl`   - wants `moe/out/post_route.dcp`
- `scripts/path_analysis.tcl` - wants `moe/physopt/post_physopt.dcp`
- `scripts/sim.cmd gl`        - wants `moe/netsim/moe_netlist.v`
